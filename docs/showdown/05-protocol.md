## 1. What is, and is not, in `battle.log`

* A fixture "step" is the slice of the log between two decision boundaries (`docs/design/FIXTURES.md`); a mid-turn or end-of-turn request ends a step.
* `battle.log` is `string[]`; **one entry = one protocol line** `'|' + parts.join('|')`, with one exception: a **split triple** is three
  entries (`|split|pN`, secret line, public line) and the public entry can be the empty string `''` (section 2.3). A fixture's
  `steps[].log` / `end.log` are slices of exactly this array. Verified: every entry starts with `|` except the empty public entries
  (none occurred); none contains `\n`.
* **Not in the log** (all go through `battle.send(...)`, `Battle.send` is the constructor's `options.send`):
  * `|request|{json}` — `Side.emitRequest` (`sim/side.ts:521-525`) sends `sideupdate` `"p1\n|request|..."`; `makeRequest` (`sim/battle.ts:1381`)
    writes nothing to the log (only team-preview formats write `|teampreview|`, `battle.ts:1400`; not this format).
  * `|error|[Invalid choice] ...` / `[Unavailable choice] ...` — `Side.emitChoiceError` (`sim/side.ts:527-535`) is a `sideupdate` to that side
    only, followed by a re-sent request with `"update":true` when the rejection leaked a hidden fact. A rejection never touches `battle.log`
    or the PRNG. The fixtures keep both in `steps[].choices[].error/.request`.
  * the `end` JSON (`winner, seed, turns, p1, p2, p1team, ..., score, inputLog`; `sendUpdates`, `battle.ts:3265-3306`) is a separate `end` message.
  * `|debug|` (debug mode off), `|chat|`, `|raw|`, `|showteam|`, `|rated|`, `|poke|`/`|clearpoke|`/`|teampreview|`, `|swap|`, `|-center|`: not emitted
    in this format (section 3.13).
  Confirmed: the corpus has no `request`, `error`, `sideupdate`, `update`, `end` kind.
* `sendUpdates` (`battle.ts:3265`) ships `log.slice(sentLogPos)` to the stream after every input line; the omniscient view is the raw log.
  The other views are derived from the same log by `extractChannelMessages` (`battle.ts:33-59`, `splitRegex` at `:33`): for a `|split|pN`
  triple the omniscient channel (-1) and player N get the **secret** line, everyone else the **public** line, and an empty public line
  is dropped. This is why the sink must produce both lines for every split: the harness compares the raw log.
* Debug-only guards that write `|message|` lines (`LINE LIMIT EXCEEDED` after > 1000 unsent entries `battle.ts:588-592`, `STACK LIMIT`
  `:582-585,772-775`) are harness crashes, not behavior to mimic.

## 2. Primitives (`sim/battle.ts:3069-3144`)

### 2.1 `add(...parts)` and stringification (`battle.ts:3091`)

No function part: `log.push('|' + parts.join('|'))`. `Array.prototype.join` applies, so:

* `string`: verbatim, **no escaping** (a `|` or newline in a name would corrupt the line; none occur here). Literals, `'[from] ' + x.fullname`, templates.
* `number`: decimal integer; `-0` prints `0` (`-unboost` of 0 stages is `boostBy = -boostBy`; 2 such lines in the corpus). `|turn|N`, `-boost` amounts, `|gen|9`, `|teamsize|pN|6`, `-hitcount`.
* `boolean`: `true`/`false` (never observed).
* `null` / `undefined`: **empty string, but the field stays**: `-formechange|p|Species|` (3rd arg `message` undefined, `pokemon.ts:1471-1477`), `|player|p1|Alice||` (avatar `''`,
  rating `''`, `battle.ts:3253`).
* `Pokemon`: `Pokemon.toString` (`pokemon.ts:531`) = `isActive ? getSlot() + fullname.slice(2) : fullname`, with `fullname = illusion ? illusion.fullname : this.fullname`.
  So **`p1a: Name` while active, `p1: Name` otherwise** (bench, switched out, fainted and processed). `getSlot()` = side id + `'abcdef'[position]` (`pokemon.ts:520`).
* `Side`: `Side.toString` (`side.ts:353`) = `p2: Bob` (id, colon, **player name**); used by `-sidestart|p2: Bob|...`.
* `Move` / `Ability` / `Item` / `Condition` / `Species` / `TypeInfo` object: **`.name`** (`BasicEffect.toString`, `dex-data.ts:143`; `TypeInfo`, `:287`), no prefix:
  ``[from] ${sourceEffect}`` on `switch` gives `[from] U-turn`; `add('-enditem', p, item)` gives `Sitrus Berry`.
* explicit `effect.fullname`: Move `move: X` (`dex-moves.ts:477`), Ability `ability: X` (`dex-abilities.ts:46`), Item `item: X` (`dex-items.ts:109`), Species `pokemon: X`
  (`dex-species.ts:287`), Nature `nature: X` (`dex-data.ts:154`), **Condition = its bare name** (default `fullname = name`, `dex-data.ts:129`). Used by ``[from] ${name}`` in
  `spreadDamage` and `heal`.
* function (`getHealth`, `getFullDetails`): triggers the split mechanics (2.3).

Condition names (`sim/dex-conditions.ts:690-700`): every `data/conditions.ts` entry carries an explicit `name`, lowercase for statuses and volatiles (`brn`, `par`, `slp`, `frz`, `psn`, `tox`,
`confusion`, `flinch`, `trapped`, `partiallytrapped`, `lockedmove`, `twoturnmove`, `choicelock`, `mustrecharge`), CamelCase for weathers (`RainDance`, `SunnyDay`, `Sandstorm`, `Snowscape`);
a condition that lives inside a move/ability/item takes that effect's display name **without** the `move: ` prefix (`Grassy Terrain`, `Stealth Rock`, `Spikes`, `Leech Seed`, `Salt Cure`, `Reflect`);
`Recoil`/`Drain` are special-cased; an id with no record at all becomes `{name: id}` (`highjumpkick`, `stealeat`). Observed `[from]` forms of
`-damage`: `item: Life Orb`, `brn`, `psn`, `Recoil`, `recoil`, `confusion`, `Sandstorm`, `Stealth Rock`, `Spikes`, `Salt Cure`,
`Leech Seed`, `Spiky Shield`, `move: Infestation` (+`[partiallytrapped]`), `ability: Rough Skin`, `pokemon: Mimikyu-Busted`, `highjumpkick`.
**The literal is chosen at each call site** (e.g. `-sidestart|p2: Bob|Reflect`, `|Spikes` but `|move: Light Screen`, `|move: Tailwind`,
`|move: Stealth Rock`: `data/moves.ts:14870,17513` vs `10343,18898,17827`). The port must copy each handler's literal; the keyed
list in section 2 of `05-log-shapes.txt` is the inventory.

### 2.2 `addMove` / `attrLastMove` / `retargetLastMove` (`battle.ts:3115-3144`, `lastMoveLine` at `:170`, init `-1` at `:258`)

* `addMove(...args)` pushes `'|' + args.join('|')` and sets `lastMoveLine = log.length` (before the push). Callers: `useMoveInner` (`battle-actions.ts:457`,
  `|move|`), `-anim` (`battle-actions.ts:801,898`, `data/moves.ts:4647,17240,17276`, `data/items.ts:4780`), and the Choice-lock/Gorilla-Tactics fail paths
  that print a bare `|move|p|Name` (`data/conditions.ts:342`, `data/abilities.ts:1663`).
* `attrLastMove(...args)` edits **the line at `lastMoveLine`, wherever it is in the log**, never the last line:
  1. `lastMoveLine < 0` → no-op.
  2. line starts with `|-anim|` and `args` contains `[still]` → **delete that entry** (`splice`) and set `lastMoveLine = -1` (never observed).
  3. else if `args` contains `[still]` → field index 4 (the target) of the line is set to `''` first ("if no animation plays the target must not be known").
  4. append `'|' + args.join('|')` to the line. Repeated calls append repeatedly: `[still]|[still]` and `[still]|[still]|[spread] ` occur (Life Dew pushes one
     `-fail|p|heal` + `[still]` per full-HP target, `battle-actions.ts:1192-1193`).
* `retargetLastMove(p)` replaces field index 4 with `p.toString()` (`pokemon.ts:806,815,842`: redirect/last of `targets`; `battle-actions.ts:900`: first hit of a
  `smartTarget` move).
* **There is one `lastMoveLine`, not a stack.** A nested `useMove` (Dancer `battle-actions.ts:338-343`, Magic Bounce) calls `addMove` again, so any attr the *outer*
  move applies later (`[spread]` at `battle-actions.ts:614`, `[miss]` `:632,738`, `[still]`) lands on the **inner** line. Verified shape:
  `|move|p2b: Espeon|String Shot|p1b: Spidops|[from] ability: Magic Bounce|[spread] p1a,p1b`. Implement it as one absolute index into the sink.
* The harness asserts that no already-flushed entry is edited later (`tools/oracle/lib/session.mjs`: the delivered slices must concatenate to the final `battle.log`, else `anomalies`); keep the index absolute across turns anyway.

Attr producers and the tags they add (appended in call order):

* `[from] fullname`: `useMoveInner` appends ``|[from] ${sourceEffect.fullname}`` (`battle-actions.ts:452`); `sourceEffect` is the explicit option or `battle.effect` when
  `effect.id` is set (`:387`), except `instruct`/`custapberry`. Seen: `[from] lockedmove`, `[from] ability: Dancer`, `[from] ability: Magic Bounce`.
* `[anim] X`: `data/moves.ts:5229,9770,16225,19221` (Fickle Beam / Ivy Cudgel / Shell Side Arm / Tera Blast): `[anim] Tera Blast Ground`.
* `[notarget]`: `battle-actions.ts:462,511`, followed by `add('-fail', user)` (gen >= 5). Verified: 3002/3002 are followed by `|-fail|<user>`.
* `[spread] s1,s2`: end of `trySpreadMoveHit` (`battle-actions.ts:614`), only if `move.spreadHit` (`targets.length > 1 && !smartTarget`, `:547`): ``'[spread] ' + hitSlot.join(',')``
  over the targets **still hit** after the steps; an empty list gives the literal `[spread] ` (trailing space; 414 lines). Order = `getMoveTargets` order: allies first for
  `allAdjacent`, then foes a, b (`[spread] p2b,p1a,p1b`).
* `[miss]`: `battle-actions.ts:632` (Invulnerability) and `:738` (accuracy), only when `!move.spreadHit`, immediately before `add('-miss', user, target)`. Verified: 2206/2208 non-spread
  `[miss]` lines are followed by `-miss|user|target` (in the other 2, Protean/Libero's `-start|p|typechange` comes first).
* `[still]`: every "move failed" path, each right after a `-fail`: `battle-actions.ts:592,643,825,844,1040,1165,1193,1203,1296,1352` (`:462,511` use `[notarget]`), plus `data/moves.ts`
  (30 sites: Substitute, Doodle, charge moves, ...), `data/conditions.ts:310,343,521,599`, `data/items.ts:4779` (Power Herb), `data/abilities.ts` (Damp, Dazzling, Armor Tail,
  Queenly Majesty, Gorilla Tactics). Blanks the target. Verified: all 7822 `[still]` move lines have an empty target and no empty target lacks `[still]`.

### 2.3 `addSplit`, HP-dependent lines and the triple (`battle.ts:3081-3112`)

```
add(...parts) with >= 1 function part:        // evaluated NOW, in order
    for part in parts: if function: r = part(); side = r.side; secret.push(r.secret); shared.push(r.shared)
                       else: secret.push(part); shared.push(part)
    addSplit(side, secret, shared)
addSplit(side, secret, shared?):
    log.push('|split|' + side)            // entry 1
    add(...secret)                        // entry 2: the line for player `side` and for the omniscient log
    shared ? add(...shared) : log.push('')   // entry 3: everyone else; '' if no shared line
```
* `|split|pN`: `N` is the **owner** of the Pokémon whose HP/details are hidden (`getHealth().side = this.side.id`). Verified: for 148,915 triples the `pN` equals
  the side of the ident in the secret line.
* Producers of function parts / splits. The corpus contains only the first four kinds (148,915 triples = 94,033 `-damage`, 35,341 `switch`, 19,392 `-heal`, 149 `drag`), and no
  HP-bearing line occurs outside a triple:
  * `Pokemon.getHealth` (`pokemon.ts:2060`): `-damage` (`battle.ts:2148-2162` spreadDamage, `:2252-2258` directDamage), `-heal` (`battle.ts:2284-2301`, `:2800` Revival
    Blessing; `pokemon.ts:1505` `[silent]` after `updateMaxHp`; `data/moves.ts:8374,10598,20942`; `data/conditions.ts:432`), `-sethp` (`data/moves.ts:13142,13144`, Pain Split — not in scope).
  * `Pokemon.getFullDetails` (`pokemon.ts:544`): `switch`/`drag` (`battle-actions.ts:146-148`), line shape `|switch|IDENT|DETAILS|HP[|[from] Effect]`. The function result
    is ONE part containing `|` (`details|hp`), which is why a switch line has 4 fields.
  * `addSplit` called directly with an explicit secret and no shared line: `-hint` for one side (`battle.ts:3073`; reachable only via Ogerpon's invalid Tera type,
    `battle-actions.ts:1921`; never observed), `-candynamax` (multi), `poke` (team preview). Their public entry is `''`.
* Secret and public lines are identical except the HP field; verified 148,915/148,915 (same kind, same arity, all other args byte-equal).

### 2.4 `getHealth` — HP strings and the percentage rule (`pokemon.ts:2060-2104`)

```
if hp == 0:   secret = shared = "0 fnt"            // no status suffix even if the mon had one (0 lines with "0 fnt <status>")
secret = "{hp}/{maxhp}"
shared = {                                         // HP Percentage Mod / gen >= 7 branch, pokemon.ts:2075-2082 (reportExactHP, Champions branches are off)
    pct = ceil(100*hp/maxhp);  if pct == 100 && hp < maxhp: pct = 99;   "{pct}/100" }
if status != "": secret += " " + status; shared += " " + status     // status id: par brn psn tox slp frz ('tox' stays 'tox' here)
```
Integer form (exact, no float issue because a non-integer quotient is ≥ 1/maxhp away from an integer): `pct = (100*hp + maxhp - 1) / maxhp`, then the 99 clamp.
* `hp ≥ 1` always gives `1..100`, never `0/100`; `100/100` iff `hp == maxhp`; `99/100` is possible with `hp < maxhp` (clamp fired 194 times); `1/100` for tiny hp (689).
* Verified over **148,915 secret/public pairs (0 mismatches)**; the sample discriminates the alternatives: `Math.round` would differ in 48,917 pairs, `floor` in 95,882;
  16,819 pairs carry a status word (copied verbatim to both lines), 19,241 are `0 fnt`.
* The secret line can never be told from the public one by looking at `/100` in general; use the position in the triple. (In this corpus `maxhp` ranges 201..645, so a secret
  line never ends in `/100`.)
* The HP is read when the part is evaluated, i.e. **after** the damage/heal was applied and **before** any faint processing (the `-damage ... 0 fnt` precedes `|faint|`).
* For a disguised Illusion mon the HP is the **real** mon's (verified, section 4).

### 2.5 `hint(text, once?, side?)` (`battle.ts:3069-3079`)

`if (hints.has(key)) return;` runs on every call but the set is only filled when `once` is true; so a non-`once` hint is printed every time and only
`data/abilities.ts:2085` (Illusion Level Mod) is `once` (verified: max 1 per battle, vs. up to 10 for Fake Out's hint). `side` given → `addSplit(side.id, ['-hint', text])`
(public `''`); otherwise `add('-hint', text)`. Some hints are written directly as `add('-hint', ...)` (`battle-actions.ts:314`, `data/moves.ts:3504,15447`).

### 2.6 `|t:|`, blank lines, flushes

* `add('t:', Math.floor(Date.now()/1000))` → `|t:|<unix seconds>` at `battle.ts:193` (constructor, first entry) and `battle.ts:2938` (start of every `turnLoop`, always right
  after `add('')` at `:2937`). Fixtures store the bare `|t:|`. Verified: 56,114 = 2050 + 54,064; every non-first `|t:|` is preceded by a blank `|` entry.
* `add('')` → entry `'|'` (blank line): `turnLoop` (`:2937`), the `residual` action (`:2816`), `win` (`:1533`). 92,398 occurrences.
* A turn can contain several `|`, `|t:|` pairs (a mid-turn switch request resumes `turnLoop`). Flush points do not change the log content.

## 3. Message grammar

Notation: `POKE` = `pNx: Name`; `NOSLOT` = `pN: Name` (an inactive mon **or a side**, whose `Name` is the player name); `SLOT` = `pNx`; `SIDE` = `pN`;
`DETAILS` = section 4; `HP` = section 2.4 (secret line `hp/max[ st]`, public `pct/100[ st]`, or `0 fnt`); `E` = effect string in whichever form the call site writes
(`move: X`, `ability: X`, `item: X`, bare name, bare id). `{n}` = occurrences in the corpus. Optional suffixes in `[...]`; `[from] E` may be followed by `[of] POKE`.
Tag inventory seen: `[anim] [broken] [damage] [eat] [from] [fromitem] [miss] [move] [msg] [notarget] [of] [partiallytrapped] [silent] [source] [spread] [still] [upkeep]
[weak] [wisher]`. Unseen but present in in-scope sources: `[fatigue]` (confusion after a locked move, `data/conditions.ts:167`), `[forme]`
(`data/moves.ts:9177`), `[persistent]`, `[zeffect]` (n/a). `[consumed]`, `[weaken]`, `[identify]` do not exist in any in-scope source; `[ability]` (`pokemon.ts:1930`, Mummy/Lingering Aroma), `[ohko]` and `[fail]` come only from effects outside the scope.

### 3.2 Turn structure and end

```
|turn|N                    battle.ts:1789 (end of endTurn, after the typechange-sync lines below). N = 1, 2, ... consecutive: verified 2050/2050
|upkeep                    battle.ts:2821, last line of the `residual` action, omitted if the battle ended in residuals; preceded by `|` (blank) at :2816
|-start|POKE|typechange|T1[/T2]|[silent]     battle.ts:1721 (and `|-start|POKE|typeadd|T|[silent]` at :1725): per active mon at endTurn, before `|turn|`, when its apparent type differs from its real type; 12 seen
|                         win/tie: battle.ts:1533, then
|win|PlayerName           battle.ts:1535-1537 ("A & B" only in multi)      {2050}; Alice 1042, Bob 1008
|tie                      battle.ts:1539                                   (0 seen; only via turn > 1000 / forcetie, `battle.ts:1844`)
```
Order inside one turn: `|` + `|t:|` (turnLoop) → actions (`|move|`, `|switch|`, `|-terastallize|`, ...) → `|` (residual) → residual effects → `|upkeep` → (faint replacement
requests: the step ends here) → `|turn|N+1`. A mid-turn switch request (U-turn, forced replacement) ends the step; the answer resumes with `|`, `|t:|`.
Verified entry after `|upkeep` (36,182): `|turn|N` 23,425; a blank `|` 12,508 (the turn is suspended for faint replacements: the step ends at the request, the answer resumes `turnLoop` with `|`, `|t:|`, `|switch...`);
`-enditem` 242 (end-of-turn `Update` triggers such as an eaten Sitrus Berry + its `-heal`), `-start` 6, `-end` 1 (also before `|turn|`). `|turn|N` is the last entry of its step and is always followed by the blank `|` of the next `turnLoop`.

### 3.3 Move flow

```
|move|POKE|MoveName|TARGET[|[from] E][|[anim] X][|[spread] SLOTS][|[miss]][|[still]][|[notarget]]      {119,788}
```
`TARGET` is `${target}` of `useMoveInner` (`battle-actions.ts:457`), the *chosen/random* target before redirection: a `POKE`; a `NOSLOT` when the chosen slot holds a
fainted mon (3002 lines, always with `[notarget]` and then `|-fail|user`; 4 field moves such as Stealth Rock show the fainted `NOSLOT` without `[notarget]`); or the empty string
when `[still]` blanked it. `Hidden Power` is printed by name `Hidden Power`. Self/ally-side moves target the user (`|move|p2b: Reshiram|Tailwind|p2b: Reshiram`).
Retargeting (Follow Me, `retargetLastMove`) overwrites the target (section 2.2). `[from]` is `sourceEffect.fullname` (`lockedmove`, `ability: Dancer`, `ability: Magic Bounce`).
Tag order seen: `[from] [miss]`, `[from] [spread]`, `[from] [notarget]`, `[from] [still]`, `[still] [spread]`, `[still] [still] [spread]`.

### 3.11 Bracket-tag glossary (observed tags; positions are fixed per call site, order of tags in a line listed)

* `[from] E` — the cause. Forms: `move: X` / `ability: X` / `item: X` / `pokemon: X` (explicit `fullname`), bare condition name or id (`brn`, `confusion`, `Recoil`, `Grassy Terrain`, `lockedmove`, `stealeat`, `highjumpkick`),
  literal `drain` / `recoil`, or a Move name through template interpolation (`switch`). Carried by `-damage -heal -status -start -fieldstart -weather -fail -immune -item -enditem -boost(item only) -setboost
  -curestatus -sideend -formechange -transform -ability switch move`.
* `[of] POKE` — the *source* mon. Follows `[from]` (`from of` order in 5,100 lines: `-enditem -weather -item -fieldstart -fail -status -start -ability -sideend`). Appears **without** `[from]` on
  `-singleturn|p|Helping Hand/move: Instruct|[of] p`, `-start|p|move: Yawn|[of] p`, `-activate|p|move: Trick/Infestation|[of] p`, `-fieldstart|move: Trick Room|[of] p`, `-sideend|…|move: Toxic Spikes|[of] p`,
  `-block|p|ability: X|[of] p`, `cant|p|ability: X|Move|[of] p`. For `-damage`/`-heal` with a non-Move effect it is present iff a source exists and `source != target` (always for an Ability effect in `-damage`).
* `[silent]` — no text for the client. Usually last (`-end -heal -clearnegativeboost -start -detailschange -singlemove -curestatus`); exceptions: `-enditem|p|Item|[silent]|[from] move: Trick` and `...|[silent]|[from] ability: Pickpocket|[of] p`;
  `-end|p|Infestation|[partiallytrapped]|[silent]`; `-curestatus|p|st|[from] ability: Natural Cure|[silent]`.
* `[eat]` — `-enditem|p|Berry|[eat]` from `eatItem` (`pokemon.ts:1783`, `data/abilities.ts:758`). `[msg]` — `-curestatus|p|st|[msg]` (not silent, `pokemon.ts:1676`) and `-formechange|p|Species|[msg]`.
* `[upkeep]` — `-weather|NAME|[upkeep]` residual tick. `[weak]` — `-fail|p|move: Substitute|[weak]` / `Shed Tail` (too little HP). `[damage]` — `-activate|p|move: Substitute|[damage]` (hit absorbed).
  `[broken]` — `-activate|p|move: X|[broken]` (Protect broken by Hyperspace Hole/Fury, Phantom Force; plain Feint has none). `[fromitem]` — `-activate|p|ability: Protosynthesis/Quark Drive|[fromitem]` (Booster Energy).

  `-damage` / `-end`. `[anim]`, `[miss]`, `[still]`, `[notarget]`, `[spread]` — attrs on `move`/`-anim` lines (2.2).
* Never in this corpus and not produced by any in-scope source: `[consumed] [weaken] [identify]`; produced only by out-of-scope effects: `[zeffect] [persistent] [ability] [ohko] [fail]`; in scope but unobserved: `[fatigue] [forme]`.

## 4. Details strings and identity

```

    + (level == 100 ? "" : ", L" + level)
```

* There is no `Pokemon#getDetails` in this commit (the comment at `data/rulesets.ts:2930` is stale): the pieces are the stored `details` field, `getUpdatedDetails` and `getFullDetails`.
* Flag combinations in the corpus (`kind: flags`): `switch`: `L+G` 24,819, `L` (genderless) 8,262, `L+G+tera` 1,121, `G` (level 100) 624, `L+tera` 451, `G+tera` 34, `L+G+shiny` 21, `L+shiny` 7, `G+shiny` 2;

* **Ident name ≠ species forme.** `Pokemon.name = set.name.substr(0, 20)` (`pokemon.ts:334`), and an empty/equal `set.name` is replaced by `baseSpecies.baseSpecies` (`:329-330`). The random-team generator always supplies

  31,658 switch-like lines have `ident name == details species`, the rest differ only by the forme suffix. `fullname = "pN: Name"` is fixed at construction (`:335`); forme changes never change it.
  Names in this format contain only letters, space, `-` and one digit (`Porygon2`); no `:` or `|`. Parse an ident by splitting at the first `": "`.
* **Illusion** (`data/abilities.ts:2056-2096`; Illusion Level Mod `data/rulesets.ts:2923`): `BeforeSwitchIn` sets `illusion` = the last unfainted party member to the right of the user. While it is set:
  `Pokemon.toString` prints the **disguise's** name (`pN` + user's real slot letter + `: ` + illusion name); the `switch` details are the **disguise's** `getUpdatedDetails` with the **disguise's level** (hence also its
  gender/shiny); `-terastallize`, `-formechange`, `-damage ... [of]` etc. use the disguise name; but the split HP is the **real** mon's (`hp/maxhp` secret, percent public). When it ends (`onEnd`: on a damaging hit, or a Tera that would
  expose an Ogerpon/Terapagos disguise; switching out ends it silently via `beingCalledBack`): `illusion = null`, then `|replace|POKE_real|<real getUpdatedDetails() — no tera, real level>`, `|-end|POKE_real|Illusion`, `|-hint|Illusion Level Mod is active, so this Pokémon's true level was hidden.` (once per battle).
  `Illusion.onFaint` just clears the field (no lines). Verified *(ad hoc, replaying teams through `Session`)*: in 64 battles with a Zoroark, 83 disguised switch-ins have the secret max HP of the Zoroark, the ident/details of the disguise team member, and that member's
  level+gender (the level differs from Zoroark's in 78; the other 5 coincide), and all 65 `|replace|` lines equal the real Zoroark's `getUpdatedDetails()`.
* **Tera**: `|-terastallize|POKE|Type` (`battle-actions.ts:1930`); the Tera type then shows as `, tera:Type` in later `switch`/`drag` details and in `detailschange` lines emitted while terastallized; `replace` and faint-time
  `detailschange` never carry it (`terastallized` is deleted first, `battle.ts:2572`; the tera suffix is added at `pokemon.ts:552`). `Stellar` appears as `tera:Stellar`. `-terastallize` itself carries no details.
* Permanent forme change (`formeChange(..., isPermanent)` `pokemon.ts:1438-1478`): `|detailschange|POKE|<details>[, tera:T]`, then `updateMaxHp` (`|-heal|...|[silent]` if max HP changed, `:1505`) and `setAbility` messages.
  Non-permanent: `|-formechange|POKE|Species|(msg)[|[from] ability: X]`; Mega/Primal/Burst lines are n/a. `Pokemon.details` of a mon that fainted with `formeRegression` is rewritten and announced with
  `|detailschange|NOSLOT|DETAILS|[silent]` (`battle.ts:2574-2577`).

## 5. Porting checklist (things that bite)

1. **Entries, not lines.** Keep the sink a `Vec<String>`; push `|split|pN`, secret, public as three entries; the public entry of a secret-only split is `""`. Blank line is the entry `"|"`.
2. **Stringify at `add` time** with the active/inactive rule for idents; a mon is `pNx: Name` until `isActive` is cleared (switch-out, faint processing), so `-hitcount`, `-heal` (Revival Blessing),
   `|move|` targets pointing at fainted slots, `[of] <fainted/benched>` and the `detailschange ... [silent]` after a faint are `pN: Name`.
3. **Ident name is never the forme**; the species forme only lives in DETAILS. With Illusion, name/details/level/gender/shiny are the disguise's while HP is the real mon's.
4. **HP percent = ceil, clamped to 99 when hp < maxhp**, `0 fnt` for hp 0 without status, status word on both lines, evaluated after the HP change. Secret/public decided by position, not by `/100`.
5. **null/undefined args keep their field** (`-formechange|p|Species|`, `|player|p1|Alice||`); a trailing `[spread] ` has a space; `-0` prints `0`.
6. **`Effect` object → `.name`, `.fullname` → prefixed**; conditions have bare names (lowercase for statuses/volatiles, CamelCase for weathers); a move's condition uses the plain move name; `tox` → `psn` in `[from]` of `-damage` only.
   Copy each call site's literal (`move: Tailwind` vs `Reflect`, `Protect` vs `move: Protect`, `RainDance`).
7. **`attrLastMove` is a pointer, not a stack.** One absolute `last_move_line`; set by `move`/`-anim`; `[still]` blanks field 4 (or deletes a `-anim` line); tags append repeatedly; nested moves steal the pointer; `retarget` rewrites field 4.
   `[spread]` is appended at the end of `trySpreadMoveHit`, even with zero targets left (`[spread] `).
8. **Order inside a hit**: `-supereffective|-resisted` then `-crit` are printed by `getDamage` for every target *before* the first `-damage` line; `-hitcount` after the faint messages; the `[miss]` attr is applied to the
   `move` line first and the `-miss` line is added right after (Protean/Libero's `-start` can sit between); ability messages (`-ability|p|X|boost`) before the `-boost` they cause; drain `-heal` right after its `-damage`.
9. **`|t:|` / `|` / `|upkeep` / `|turn` placement**: `|`,`|t:|` at every `turnLoop` entry (also after mid-turn switch requests, which end a step); `|`, effects, `|upkeep` for residuals (no `|upkeep` if the battle ended); `|turn|N` last. Normalize `|t:|<n>` to `|t:|` when diffing.
10. **Win**: `|` then `|win|<player name>` (names are the `setPlayer` names, no escaping); both sides empty → the side of the last fainted mon wins; `|tie` is turn-limit/forcetie only.
11. **No log lines for**: requests, choice errors, the `end` JSON, PRNG draws, rejected choices.
12. **Free text and names are raw UTF-8**, no escaping anywhere; hints use ASCII apostrophes and `é`.
13. **Once-only hint** (Illusion Level Mod) must be deduped per battle; all other hints print on every call.
14. **Sleep Clause**: `|-message|Sleep Clause Mod activated.` then `|-hint|Sleep Clause Mod prevents ...` (rule's `onSetStatus`, `data/rulesets.ts:1395-1396`) directly after the move line, no `-fail`.
15. **Do not mimic** `LINE LIMIT`/`STACK LIMIT` `|message|` lines; they are crashes.
16. **Identifier spellings** (all distinct): `p1` (side id: `|split|`, `|player|`, `|teamsize|`), `p1a` (slot only: `[spread] p1a,p1b`), `p1a: Name` (active ident), `p1: Name` (inactive ident **or** a side with its player
    name: `-sidestart|p2: Bob|...`), bare `Name` (`[wisher] Vaporeon`, `|win|Alice`, `|-formechange|p|Species|`). Nothing is escaped; none of these strings contain `|` here.
17. **`getHealth` runs when the line is added** (current hp, current status); `switch` lines carry the mon's *current* hp (a returning mon is not `100/100`).
